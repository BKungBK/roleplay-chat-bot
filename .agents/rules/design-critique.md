# Design Critique Guidelines & Rules

1. **Visual Rigor**:
   - Evaluate layout hierarchy, typography scaling, and palette distinctiveness (avoid generic AI defaults).
2. **Mobile-First & Ergonomics**:
   - Verify touch target dimensions ($\ge 44\text{px}$), safe areas, and bottom-bar reachability.
   - Prevent virtual keyboard overlap with input controls.
3. **Actionable Review Output**:
   - Categorize feedback into **Strengths**, **Gaps**, and **Actionable Code/CSS Fixes**.
