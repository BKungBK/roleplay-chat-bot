# Frontend Design Principles & Guardrails

1. **Avoid Generic AI Defaults**:
   - Avoid standard cream background + serif + terracotta accent.
   - Avoid near-black background + single acid-green accent.
   - Avoid broadsheet layout + zero border-radius unless explicitly requested by the brief.

2. **Subject-Grounded Design**:
   - Establish a concrete subject, target audience, and primary page goal before designing.
   - Pick 4–6 cohesive, intentional hex colors; avoid generic browser default colors.
   - Select display & body fonts deliberately with clear type scaling.

3. **Restraint & Signature Element**:
   - Spend boldness on a single memorable signature element. Keep surrounding elements clean and disciplined.
   - Ensure motion/animations are intentional micro-interactions or entrance moments rather than clutter.

4. **Intentional UI Copy**:
   - Write clear, active, user-centric interface copy (e.g., "Save changes" instead of "Submit").
   - Handle empty states and errors with direct actionable guidance.
