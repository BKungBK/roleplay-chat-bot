# User Research Guidelines & Rules

1. **Target Archetype Identification**:
   - Determine target roleplay user motivations (Immersion, Storytelling, Casual Companionship).
2. **Feature Validation**:
   - Validate user expectations around bot persona depth, memory retention, and interaction controls before scaffolding UI or endpoints.
3. **Data Translation**:
   - Translate user feedback directly into database fields (e.g., `personality`, `speech_style`, `boundaries`) and UX features.
